## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues; use the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Use `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repo with root `GLOSSARY.md` and `docs/adr/`. See `docs/agents/domain.md`.

### Implementation revisions

Before exploring another repository, verify the requested revision. See `docs/agents/domain.md#implementation-revisions`.

### FSM and runtime

For host state machines, transitions, continuation, retries, lifecycle, ingress, or batch workflows, read `docs/agents/fsm-runtime.md`.

### Architecture reports

When generating an architecture-review HTML report, save it in `docs/architecture-reviews/` (create the folder if needed).
