## Part D. No migration/backfill of existing data vs. the retained per-execution migration contract

- Evidence that existing adapter upgrades never rewrite execution rows: SQLite only adds tables and bumps the adapter version (B10). Execution records must carry `SchemaVersion == 1` or fail validation (B10). MySQL accepts only version 1 (B11). No backfill code exists today. This matches the issue #31 exclusion of migrating or backfilling existing data, which is stated only in a mutable issue body.
- The retained contract is `ExecutionMigrator` plus `AuthorizedMigration`. It is per execution, authorized by the host (including replays), pins `OriginalRequest`, and is blocked after commit begins or work succeeds (B9). Both adapters run it through shared conformance (`RunMigration`; MySQL wiring in B12).
