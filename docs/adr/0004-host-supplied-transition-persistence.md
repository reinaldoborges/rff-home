# Use host-supplied persistence for transition execution

The framework defines the versioned transition-execution record and typed persistence port, while the host injects the adapter and owns domain state and its schema. Acceptance durably reserves the entity and idempotency identity; terminal history has no automatic expiry. When data shares a transaction, commit domain state, execution outcome, and enabled notification intent atomically. Otherwise, persist work success before an idempotent host commit that writes a receipt atomically with domain state; recover from that receipt and hand off notifications idempotently. The host commit boundary enforces expected-state and fencing checks, while versioned application codecs/references and explicit machine-version compatibility make retries restart-safe. This keeps domain ownership with the application without promising exactly-once cross-store effects.
